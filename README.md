
# Time Horizon

Time Horizon is a visual timeline for tracking life's commitments and deadlines.

## Features

- Visual timeline for tracking deadlines and commitments
- Ability to add, edit and delete tasks
- Filtering by category
- Responsive design

## Getting Started

To get started with Time Horizon, follow these steps:

1. Clone the repository: `git clone https://github.com/username/time-horizon.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Open the application in your web browser: `http://localhost:3000`

## Contributing

Contributions are welcome! To contribute to Time Horizon, follow these steps:
